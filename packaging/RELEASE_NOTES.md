## New: keep playing on this launcher if you want to

This project has closed, and its features are going into the official [sms-pc-port](https://github.com/chasem-dev/sms-pc-port) and **[SMS Launcher](https://github.com/chasem-dev/sms-launcher)** by chasem-dev, who made the port. We recommend moving to SMS Launcher. Some of you asked to keep using this launcher a while longer, so this update lets you.

### What's new in 2.1.0
- The "We've moved to SMS Launcher" screen has a new button, **Play on this launcher anyway**. It opens this launcher as you know it: your settings, HD textures, HD cutscenes, online co-op and everything else. Press Play as before.
- It asks each time you start the game, and the launcher shows a **Please move to SMS Launcher** note. **Move to SMS Launcher** (also on the About page) takes you to the switch; **Not now** hides the note until next time.
- This launcher gets no new features from here on. New work goes into SMS Launcher.

### Moving to SMS Launcher
**Get SMS Launcher** works as in 2.0.0:
1. **Backs up your memory card** to a dated `SMS PC Port save backup` folder in your home folder.
2. **Moves your saves** to where SMS Launcher looks for them, if you kept them somewhere else (`save_dir`). If you never changed it, they are already there. A memory card SMS Launcher already has is never overwritten.
3. **Downloads the latest SMS Launcher** from its GitHub releases, to your Downloads folder.
4. **Starts it**: the installer on Windows, or the AppImage on Linux.

Nothing is deleted: your disc image, mods and old saves stay where they are.

### Getting this version
- **On 1.4.0:** the launcher offers this update when it opens. Choose **Update now**.
- **On 2.0.0 or 1.3.0 and older:** download this release once.

### Downloads
- **Windows (64-bit):** `SMS-PC-Port-*-windows-x64.zip`. Unzip anywhere and run `sms.exe`.
- **Linux (64-bit):** `SMS-PC-Port-*-linux-x86_64.AppImage`. Make it executable (`chmod +x`) and run it.
